# 🌸 Link Cleaner CLI (FOK LOGPOP)

Легковесная, но невероятно стильная консольная утилита для очистки ссылок от рекламного мусора. 

Вас когда-нибудь бесили длинные ссылки с кучей непонятных символов после знака `?` (типа `utm_source`, `fbclid` и т.д.)? Этот скрипт отрезает весь этот шпионский мусор, оставляя только чистый и безопасный URL.

## ✨ Особенности
* 🎨 **Красивый интерфейс**: Удобное меню прямо в терминале.
* 🌿 **Анимация**: Плавно покачивающиеся цветочки при запуске.
* 🚀 **Скорость**: Работает мгновенно, не нагружает систему.
* 🕵️ **Приватность**: Удаляет трекинговые метки соцсетей и рекламных сетей.

## 🛠 Установка (для Termux)

Для работы скрипта нужен Python. Установка занимает меньше минуты:

1. Обнови пакеты и установи Python (если еще не установлен):
bash
pkg update && pkg upgrade -y
pkg install python -y

2. Склонируй репозиторий (замени ТВОЙ_НИК на свой логин на GitHub):

bash
git clone https://github.com/ТВОЙ_НИК/Link-Cleaner-cli.git

3. Перейди в папку с проектом:

bash
cd Link-Cleaner-cli

4. Запусти скрипт:

bash
python cleaner.py

📖 Как пользоваться

1. Запусти скрипт.
2. Наслаждайся анимацией 🌸.
3. Выбери пункт 2 в меню.
4. Вставь грязную ссылку (например: https://site.com/page?utm_source=tg&item=123).
5. Получи чистую ссылку (https://site.com/page?item=123) и скопируй её!
